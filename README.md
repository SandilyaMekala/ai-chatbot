# Development Deployment
This project was deployed as part of instructing summer camp at iCode.
This AI chatbot utilises Mistral model for Text-to-Text generation and stable-diffusion model for Text-to-Image generation. These two are combined into a single chatbot named Codie.
These models are deployed from hugging face.
Eleven labs is used for analyzing voice interactions and converting them as text.
The code is deployed from Glitch.
